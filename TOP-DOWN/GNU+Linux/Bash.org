*** what is bash
Bash is the shell or Command Language Interpreter, for GNU operating system
- the name is a pun on Stephen Bourne
  - author of the direct ancestor of the current unix shell
    - appeared in 7th ed. of Bell Labs Research version of Unix

*** sed

`sed `` sn.csv` same as `cat sn.csv`

`sed 'd' sn.csv`

/delete first line/
`sed '1d' sn.csv`

        _regex will match a string that contains either no characters or only white space characters_
        `sed '/^\s*$/d' factorial.py`

        _regex `^#` matches comment lines, so we connect `^\s*$` with an 'or' to `^#`, we insert a `|`_
        `sed '/^\s*$\|^#/d' factorial.py`

        _print only the commented lines?_
        `sed '/^#/p' factorial.py`

_create a javascript file from lat lon coordinates_
`sed `s/^/new google.maps.LatLng(/' latlon > latlon2`
`sed 's/$/)/' latlon2 > latlon3`
