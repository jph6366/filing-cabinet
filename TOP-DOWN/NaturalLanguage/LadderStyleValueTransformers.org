*** Framework

*rollout & update*

1. Generate
        vectorized JAX loop generates tokens until a turn-end token
2. Interact
        copy tokens to the host, decode them, and pass them to the environment
        Add the response tokens and turn rewards to that slot
3. Collect
        Push completed episodes to the episode pipeline
4. Update
        When the pipeline holds a full batch, pass it to the PPO update function
5. Repeat
        Return updated weights to the token generation loop

*token generation*

- Jagged KV cache
        different prompt lengths require a specialized jax.lax.scatter over token indices
- Cached prompts
        prompts stay in their GPU slot throughout generation
- Decode
        roughly 8000 tokens/sec, no prefill


*value warmup*

the risk: fresh critic starts with unreliable values
                training the lang model against it could hurt the model

the warmup: train the critic while keeping the base model weights frozen


/there is a reason value models are not reasonably used for transformer-based models/

*GAE at 2 timescales*
- within a turn
- across turns
/later TD errors contribute backwards through the episode/
