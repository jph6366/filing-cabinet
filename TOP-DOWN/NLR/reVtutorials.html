1.1. concepts

Geospatial Data Science using Geographic Information Systems

Energy Planning and Production

resource

  • the input utilized for energy generation by a generator

resource potential

  • theoretical availability of renewable energy across an area
  • quantifies the energy constant of a resource at specific location

NLR\NREL resource datasets for solar (NSRDB) and wind (WTK) resource potential

technical potential

  • the maximum amount of capacity and generation possible in an area
    • given physical, technological, and regulatory constraints
  • the measure of developable resource potential based on user assumptioms of the area
    • e.g. user may constrain developmented based on what land-use intersects/overlaps

technical potential establishes an upper boundary estimate of development potential

1.1.1. oil and gas

availability potential

  • will be represented as a combination of available gas supply and deliverable gas volumes
  • each potential power plant will have access to deliverable capacity of the nearest service line

deliverable potential

  • maximum amout of deliverable oil or gas
    • based on delivery infrastructure and assumptions of available resources

1.2. reV model

  • simulates renewable energy generation and cost potential across a landscape
  • simulates discrete generation plants with spatiotemporal constraints
  • serves a spatial coordinator for SAM, connecting energy plants to transmission network

Levelized Cost of Energy

  • average revenue per unit of electricity generated
    • that would be required to recover the costs of building and operating a generating plant during an assumed financial life

technical potential

  • represented as a function of available land after applying…
    • exclusions
    • net capacity factor (esimtated by generation module)
    • user-defined power density appropriate for specific technology
      • power density value represents the maximum potential capacity for a given unit of area \((MW/km^2)\)
  • the LCOE output provides insight into decision-making for economics, performance, and regionalized differences
    • LCOE also used in supply curves

1.4. reV inputs

full model pipeline of reV requires:

  1. SAM configuration
    • used to simulate energy generation and costs
  2. Resource HDF5 dataset
    • spatial timeseries of energy resources
  3. project points csv
    • where to run SAM configuration
  4. exclusion HDF5 dataset
    • used to model available land and capacity given technologies
  5. transmission connection csv
    • table of supply curve points representing potential power generation sites
      • and their potential interconnection tie-line distances and costs

1.4.1. SAM Configurations

  • SAM C/C++ code simulates performance and economics for a suite of energy technologies
    • reV accesses PySAM which wraps SAM C API

reV is a spatial-wise application of SAM

  • runs SAM at given location(s) to simulate given technology(s)

1.5. Resource HDF5 dataset

  • 2D array for each data variable (GHI, windspeed, air pressure, etc.)
  • time index on the y axis
    • site index on the x axis
  • `meta` stored as a struct array
    • containing `coordinate`,`timezone`, `elevation`, and other (associated with x axis)
  • 1D `timeindex` vector that contains datetime strings (associated with y axis)
  • `scalefactor` attribute on each variable that is used to translate integers back into floats where scaling is used for data storage
  • `units` attribute that stores the units for each variable

remote access using `rex` and `hsds`

  • seamlessly integrate remote resource access into reV modeling pipeline

1.6. Project Points

points that subset the data that pulled from resource datasets for a given geographic region

  • project points files must have two columns
    1. `gid`
      • index position of x axis of resource array
        • or row index of the resource meta data table
    2. `config`
      • key associated with SAM configuration in `configgen.json`
        • e.g. for wind it is `onshore`

to run make sure to have an editable install

  • `pip install -e .`
import os
import h5py
import pandas as pd
from rex import Resource
from rev_tutorial import DATA


# Path to the HDF5 resource file
RES_FILE = DATA.joinpath("ri_100_nsrdb_2012.h5")


def main():
    """Read, format, and write a project points file."""
    # Use rex's Resource class to pull out a formatted resource meta dataframe
    with Resource(RES_FILE) as res:
        meta = res.meta

    # The "gid" column is the original index and tell reV where to run
    meta.loc[:, "gid"] = meta.index

    # Now you can subset, as long as the gid refers to the original index
    meta = meta[meta["population"] < 10_000]

    # The config column tell reV which SAM config to run
    # Here we are assuming a single 'default' config will be run every where
    meta.loc[:, "config"] = "default"

    # All reV needs is config and gid, but you can include other fields
    project_points = meta[["latitude", "longitude", "gid", "config"]]

    # Save this to a project points file
    fname = "project_points.csv"
    dst = HOME.joinpath(f"tutorial_3_input_builds/make_project_points/{fname}")
    project_points.to_csv(dst, index=False)


if __name__ == "__main__":
    main()
